# GAME_DESIGN (游戏核心玩法与数值策划文档)

## 1. 游戏定位
- **游戏名称**: 每日网格擂台 (暂定名)
- **游戏类型**: 极简网格解谜 (Grid Puzzle)
- **核心玩法**: 基于 2D 网格的消除/匹配游戏。游戏采用**“主线闯关 + 每日社交擂台”**双轨制玩法，兼顾单人杀时间与熟人社交竞技。
- **目标受众**: 全年龄段玩家。主打清爽的网格数据和消除反馈，提供极强的 ASMR 级心理舒适感。

## 2. 核心模式设计 (Game Modes)
### 2.1 主线闯关模式 (Level Progression - PVE)
- **无尽的关卡**: 玩家从第 1 关开始不断向上挑战。随着关卡深入，网格的层数、方块种类、盘面复杂度会逐渐递增。
- **算法生成 (关键技术)**: 关卡**并非人工配置**，而是以“关卡号”作为随机数种子（Seed）通过算法生成。例如，全网所有玩家玩“第 142 关”时，生成的盘面完全一模一样。这保证了游戏体积极小，且关卡数量趋近于无限。
- **产出**: 闯关是玩家获取基础金币、解锁图鉴和皮肤的主要途径。

### 2.2 每日擂台模式 (Daily Challenge - PVP)
- **每日一局**: 玩家达到一定关卡（如通过第 10 关新手期）后解锁。每天零点服务器下发唯一的日期种子，生成全网统一的超高难度“魔鬼盘面”。
- **单局限制**: 每天限制挑战次数，无限放大玩家的胜负欲。
- **群排名成绩单**: 每天通关或失败后，生成一张战报，分享到微信群后形成“群排名鄙视链”。

## 3. 局内交互与容错机制
- **网格交互**: 玩家在网格上点击方块移入底部的槽位，凑齐条件（如 3 个相同）即可消除。
- **暂存槽位**: 盘面外设有一个 7 格临时存放区。槽位满且未发生消除即判定失败。
- **三大战术道具**:
  - **撤销 (Undo)**: 回退上一步操作。
  - **移出 (Extract)**: 将槽位中的 3 个方块强制移出并放在旁边，腾出空间。
  - **洗牌 (Shuffle)**: 重新打乱盘面上所有未消除方块的位置。

## 4. 局外养成与商业化变现 (Meta-game & Monetization)
### 4.1 局外养成 (Meta-game)
- **皮肤系统**: 使用闯关获得的金币，购买不同主题的方块皮肤（麻将、猫咪、赛博霓虹、立体糖果等）和背景壁纸，提供长线收集目标。
- **段位与荣誉**: 根据每日擂台的表现发放奖杯，累计奖杯可提升段位（青铜 -> 最强王者），在首页展示。

### 4.2 商业化闭环 (Monetization)
这套设计完美契合了高频高转化率的激励视频卡点：
- **获取强力道具（激励视频）**: 关卡内的“移出”、“洗牌”等救命道具，在使用完免费次数后，需看视频获取。
- **死局复活（激励视频）**: 槽位满时，看视频可复活并自动清空槽位里的 3 个方块。
- **皮肤试用/双倍奖励（激励视频）**: 过关结算时，看视频金币收益翻倍。

## 5. 技术与架构 (Technical Architecture)
- **纯前端无状态架构 (Stateless)**: 核心关卡生成算法（PRNG 伪随机生成器）与通关校验全部在客户端完成。极大降低服务器成本。
- **对象池渲染**: 2D 网格中的方块频繁销毁和生成，必须利用 PixiJS 的对象池（Object Pool）进行复用，确保在任何微信机型上都不会触发 GC 卡顿。

## 6. 关卡进阶机制与玩法解锁路线图 (Progression & Roadmap)
为了打破长期消除带来的枯燥感，游戏将根据主线关卡的推进，陆续解锁新的阵型与特殊玩法机制。

### 阶段 1：阵型的千变万化（Levels 1-10）
通过改变堆叠区域的三维结构，强制玩家改变解局思路：
- **Lv.1**：经典金字塔（Classic Pyramid），中间高四周低。
- **Lv.2**：双子塔（Twin Towers），左右两座独立高塔，迫使玩家兼顾两端。
- **Lv.3**：甜甜圈（Donut），中心镂空的环形高墙，需要“剥洋葱”式的外围突破。
- **Lv.4**：钢铁长城（Great Wall），横向极宽但极窄的阵型。
*(以上阵型将在后续关卡中循环组合)*

### 阶段 2：特殊方块的引入（Levels 11-30）
- **盲盒方块（Mystery Tiles）**：棋盘上带有“？”的方块。不到将其移入暂存区的那一刻，无法知道其真实图案。极大增加策略赌博感。
- **冰冻方块（Frozen Tiles）**：方块被冰封，不可点击。必须在其周围进行一次成功的三消后才能解冻。

### 阶段 3：特殊挑战与局外成长（Levels 31+）
- **炸弹方块（Bomb Tiles）**：带有倒计时的方块。一旦失去上方遮挡，必须在限定步数内消除，否则游戏失败。
- **强力破坏道具（Hammer）**：允许消耗大量金币，直接砸碎棋盘上的任意一个死局方块。
